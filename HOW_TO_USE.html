Laundry Desk — How to Use

Compact guide for Super Admin, Admin, Manager, Delivery and Customer users.

Super Admin configuration

Sign in with the top-level Super Admin account, then open Setup → Config. Protected settings require a secondary time-based unlock.

Pass code formula: device-local 24-hour two-digit hour followed by (minute + configured offset), default 10. Example: 09:25 → 0935. Set the offset to 0 for HHMM; valid offsets are 0–40 to keep the code four digits. The unlock is a secondary check after login and remains valid for 10 minutes.

Country, currency & tax

  1. Search and select a country.
  2. The system suggests timezone, currency and a tax profile.
  3. Timezone/currency/tax values can still be edited before saving.
  4. UAE defaults to AED / Asia-Dubai / VAT 5%.
  5. India defaults to INR / Asia-Kolkata / GST with CGST 9% + SGST 9%.

Rates include tax ON: the existing rate is the customer total and the included tax component is calculated. OFF: tax is added on top for newly priced/repriced orders. Existing orders are not retroactively repriced.

Maximum users

Super Admin sets Max active users. This counts active staff login accounts, not customers. When the limit is reached, +Staff is disabled and the backend also rejects creation/reactivation above the limit.

Configurable stages

Under Setup → Config → Stages, Super Admin can enable/disable, reorder or add custom quick-flow stages. Confirmation can be enabled if required; it is off by default.

When a stage is selected from an order, the order popup remains open. The applied stage becomes a green rounded chip with a white tick, and mobile automatically scrolls it into view.

Receive payment

Admin/Manager can tap Receive payment from Home or Account against a customer. Search/select customer, review outstanding/advance, optionally prioritize orders, enter amount and select Cash/Card/Bank/Other. Card/Bank requires a transaction reference.

Quick workflow

Garments/services must be captured before moving an order forward. Active quick stages come from Super Admin configuration; detailed wash/iron processing remains available separately.

Pickup routing

Filter/sort by Building/Block and Door No. Select several pickup requests and assign one collection boy in a single action.

Reports

Reports support Excel and PDF. Sales and cash received remain separate so customer advance/overpayment is not treated as sales.

Demo reset

Setup → System → Reset demo data clears operational transactions while retaining users, customers and configuration.

Separate the Admin accounts

Sign in with the existing elevated admin account and unlock Config. In Staff, create an active user named Super Admin, login ID superadmin, role Super Admin. Leave the PIN blank for an automatically generated private six-digit PIN. Sign in as the new Super Admin and unlock Config before changing the old admin role to Admin. Keep the old PIN unchanged.

Reports & Sales

Open Reports, then choose Overview, Sales (Admin / Manager), Customers, Operations, Payments or Calendar. Select Today, Yesterday, This week, Last week, This month, Last month, This year, Last year or Custom. Select Group by Day, Week, Month or Year where applicable. Calendar uses its own month selector. Click Excel or PDF after the report loads. Sales use order dates and include recorded tax; received payments use receipt dates and are not sales. Current due, credit and workflow workload are not period-filtered. If a Currency selector appears, choose the actual recorded currency; unattributed historical credits are flagged rather than converted.

Sales charts and synchronized stages

Reports → Sales: select Sales Summary for totals, Sales Chart for Bar/Line/Area charts, or Sales by Period for a Day/Week/Month/Year table. All three use the same date range and currency. Chart and Period share grouping. On phones use the compact Period selector. Download charts as PNG or SVG; Excel/PDF exports the active view (chart data for Sales Chart).
Order stages: Quick Flow and Detailed Flow share the physical order status. The current stage is highlighted in green, tagged milestones show ticks, and skipped milestones remain neutral. Delivered is final.

Minimal Home & appearance

Tap Theme (sun/moon icon) in the top bar on mobile or web. Choose Light, Dark or System; preferences are saved on this browser. Existing custom accent choices are retained. Work by stage filters the attention queue; Other active includes orders in hidden stages. Account overview shows current cumulative totals, not daily sales. Use Reports for date-specific sales.

Due customers & POS billing

Admin and Manager: Reports → Due customers lists current unpaid orders, including delivered orders. Search by customer, mobile or building; sort by amount, oldest unpaid or location. Excel/PDF export uses the filtered list and selected currency. The Receive payment shortcut is available when report and configured currencies match and there is only one currency. Pickup and handover display current order due and other unpaid orders separately. Enter only actual money received; payment in these forms applies to the current order. Use Customer Account to settle other orders. Print → POS bill offers 80 mm (default) or 58 mm; select matching roll width and 100% scale in the printer dialog, and disable browser headers/footers. Bag and garment tags remain separate.

Action Centre and cash settlement

Open the notification bell for new requests and assignments. Tap a notification to open its order. Reading an alert does not finish the work. Home workload counts refresh every 25 seconds while the app is visible and not busy.

Admin/Manager: use Home → Delivery team → Stops for assigned work, or Cash for cash settlement. Delivery: open My Cash, choose currency, enter the actual amount handed over and submit. The cashier confirms receipt or rejects the request. Pending requests reserve available cash; confirmation reduces cash in hand. Reconcile historical cash before confirming. Only actual cash receipts are counted, not bank/card/credit, and handovers are not new sales or customer payments.

Customer search supports name, mobile, building/block, door and customer code. Use the arrow keys to highlight a result, Enter to select and Escape to dismiss. Due customers include older unpaid delivered orders. Delivery payments remain linked to assigned orders; settle other dues through Customer Account with Admin/Manager. Closed-app push is not included. Demo reset also clears notifications and settlements.

QR scan and receive delivery cash (1.7.8)

Staff: tap the Scan icon in the header. Start camera and allow permission, or enter the printed code and press Enter. Receipt/bag QR opens the order; individual garment QR identifies its exact piece and service. Customers have no scanner. Delivery users can only view assigned orders. New garment labels include QR codes when the generator is available.

Admin/Manager: Home → Delivery team → Cash → enter received amount or Use available amount → Confirm cash received. Confirm existing pending handovers individually. The settlement history records who handed over and who received the cash. No new customer payment is created.

Demo reset: Admin → Setup → System → Reset demo data. Type RESET. Operational data, notifications and settlements are cleared; users, customers, setup, security/audit history and order numbering are retained. This is destructive; use only for demo records.
