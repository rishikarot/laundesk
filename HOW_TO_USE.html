Laundry Desk — How to Use

Mobile-first guide for Admin, Manager, Delivery and Customer users.

1. Sign in

Use your staff login ID or customer mobile number with the six-digit code. The app opens only the workspace allowed for that role.

Seeded customer test: Rishi · 9895494496 · code 123456. Ten additional dummy customers are also available.

2. Quick workflow — default

Requested · Collected · Received · In Progress · Ready · Delivered

These are flexible forward milestones, not mandatory wizard steps. Admin/Manager can tap any later stage directly. For example, a busy-day order can go from Collected → Ready → Delivered without tagging the skipped milestones.

  • Confirmation: OFF by default. Admin can enable it under Setup → Workflow.
  • Collected with no garments captured: the collection screen opens so pieces/services can be entered.
  • Detailed tracking: use Detailed stages when Washing, Ironing or Out for Delivery must be recorded explicitly.
  • Skipped stages: are not falsely marked complete; the direct stage change is recorded in history.

3. Detailed stages when required

Open an order and choose Detailed stages. The full stages are Pickup Requested, Collected, Received, Washing, Ironing, Ready, Out for Delivery and Delivered. Switch back to Quick flow at any time.

4. Manager / Admin daily work

  1. Create a Counter Order or Pickup Request.
  2. Assign pickup/delivery drivers when required.
  3. Open an order and use the primary next action.
  4. Use Payment, Driver, Print and WhatsApp from the compact action dock.
  5. Payment status stays separate from laundry status.

5. Reports

Open Reports. Use preset periods: Today, Yesterday, This Week, Last Week, This Month, Last Month, This Year or Custom. You can group results by Day, Week, Month or Year. After the report loads, use Excel or PDF in the page header to download the currently selected report and period.

Admin / Manager

  • Overview: Orders, pieces, sales, cash received, collected, delivered, average order value, current outstanding and customer credit.
  • Customers: Sales, received, outstanding, advance/credit and net position customer-wise.
  • Operations: Quick workflow queue, detailed stage counts and aging alerts.
  • Payments: Cash received by method and collection point, outstanding, credit added/applied.
  • Calendar: Daily Collected, Delivered and Cash Received values.

Delivery

Reports show only the delivery user's own assigned/completed activity and payments collected by that user.

Customer

Reports show only that customer's own orders, spend, payments, amount due, available credit and calendar activity.

6. Important reporting rule

Sales and Cash Received are different. Example: if an AED 80 order receives AED 100, Sales = AED 80, Cash Received = AED 100 and Customer Credit = AED 20.

Date filters apply to period activity. Current Outstanding, Customer Credit, Ready and In Progress show the current position so balances are not misleading.

7. Customers

Admin and Manager can add customers quickly using the blank row at the top of the Customer screen. Use Edit to change name, mobile or address. Admin can additionally disable/enable customer access and reset the six-digit login code.

8. Rates

Admin → Setup → Rates has a blank add row at the top. Existing rows can be edited in place: change the AED rate or effective date and press Save. This avoids opening separate forms for normal rate maintenance.

9. Admin setup

Admin can manage Organization Name and Address, staff, customer access, garments, services, rates and discounts. Organization details appear in the app header, receipts and print labels.

Reset demo data — Admin

  1. Sign in as Admin.
  2. Open Setup → System.
  3. Select Reset demo data.
  4. Review what will be cleared and retained.
  5. Type RESET and confirm.

This clears orders, items/tags, workflow history, payments and customer credits, then resets order numbering for a fresh test cycle. Staff users, customer accounts, pricing/catalog setup and organization settings are retained.

Mixed-service garment collection

For Counter Order or Delivery collection, choose a service first (Wash Only, Wash + Iron, Iron Only or Dry Clean), tap garment quantities, then switch services as needed. Quantities already entered are retained, so one order can contain different garments under different services.

The collection summary shows total pieces, number of services and estimated amount before saving.

Customer account / advance

Admin and Manager can open Customers → Account for any customer. Receive money even when there is no outstanding order. The system settles the oldest outstanding orders first; any excess remains as customer advance. When a later order is priced, available advance is automatically applied and appears as a debit in the wallet ledger.

Flexible Quick Flow

The quick stages are Requested, Collected, Received, In Progress, Ready and Delivered. Admin/Manager can tap any later stage directly. By default there is no confirmation popup.

Admin can enable confirmation under Setup → Workflow → Confirm stage changes. Skipped milestones are not falsely marked complete; the stage change is recorded in the order history.

Assign several pickups together

Open Orders. In Collection boy assignment, filter by Building/Block, choose the required pickup requests, select the collection boy and press Assign selected.

The Delivery user's Stops page can also be filtered and sorted by Building/Block to make building-wise collection rounds easier.

Customer location fields

Customer records now include Building/Block, Door No. and Area/Street. Use the Customers filter and sorting controls to group customers by the same building before planning collections.

Search and select a customer

In Counter Order and Pickup Request, customer selection is a searchable field instead of a long dropdown. Type any part of the customer name, mobile number, Building/Block, Door No. or customer code. Matching customers show Name, Building/Block, Door No. and Mobile. Tap the correct result to select it.
