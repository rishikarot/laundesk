# Laundry Desk — Adaptive Minimal UI
Release `1.7.8-adaptive.1` | Base `1.7.8-mobile.2` (supplied Mobile App full source) | Approved reference: Laundry-Desk-Minimal-Interactive.html.

## Deploy
Extract the GitHub Upload ZIP into the existing repository root, preserving directories. Replace `app.js`, `styles.css`, `index.html`; add these notes and the two new test scripts. Keep `config.js`, PWA files, backend, database, and unrelated site files intact. Commit to the GitHub Pages deployment branch, wait for the deployment, reload the app. Do not replace or redeploy the Supabase function or run migrations as part of this frontend release. The full-source package is an archive of the supplied source plus these changes, not a verified snapshot of the running backend. The supplied backend file does not implement all the live action-centre endpoints used by the frontend; it has intentionally not been changed. Do not overwrite a newer deployed backend from this archive.

## Implemented
- Approved minimal layout: monochrome default, consistent existing inline SVG icon library, compact header and responsive navigation, borderless financial strip, action rows, workflow stage drilldowns, delivery team cash and order details. Real business handlers reused; no demo role switching or simulated transactions introduced.
- Desktop sidebar has expanded, icon-only and completely hidden modes. Top-left control hides/restores the prior width. Group visibility, theme, density, text size and workflow-stage expansion saved in device storage per account ID. Below 900px, mobile navigation is shown without overwriting desktop settings. Preferences start at the new design defaults for accounts without saved Adaptive UI preferences.
- Mobile bottom navigation has common modules, quick creation where authorized, and More for remaining modules, appearance and sign-out. Desktop search supports Ctrl/Cmd+K and searches modules, actions and records currently loaded for the logged-in account (not a server-wide search). QR scan, notifications and original customer selector retained. Existing order detail dialog uses a right-hand sheet on wide desktop; it remains a modal, so background editing is blocked.
- Pure White, Sage, Warm Linen, Midnight, System and existing custom accent. Adjustable font size and density on common UI components; existing >=16px mobile editable field safeguards retained. Existing PWA behavior unchanged.
- Financial overview preserves Payments collected, Outstanding and Customer credit; Active orders added; Delivery cash is explicitly recorded cash held by delivery staff, not revenue or total shop cash. Currency amounts are grouped by code and missing-currency amounts shown separately with a small 'Currency not recorded' label and reconciliation note. No unknown amounts are silently dropped, converted or relabelled AED. No historical data is modified. The real currency must be verified against original receipts and assigned by an authorized, audited backend correction; the deployed backend and live records were not available for verification in this release.
- Existing API calls, payment allocation, cash settlement, workflow handlers, QR lookup, receipt and report exports are retained. The production frontend is not a literal copy of the demo prototype: existing transaction screens and access model remain, with common styles and navigation applied. No live DB access or write performed.
